# Glossary part 5

Parts: [GLOSSARY](GLOSSARY.md) | [part 2](GLOSSARY_part2.md) | [part 3](GLOSSARY_part3.md) | [part 4](GLOSSARY_part4.md) | [part 5](GLOSSARY_part5.md)

- **Transcoding**: On-demand loading of Delta column data into Direct Lake memory
- **UA**: Universal Accessibility, as in the PDF/UA accessible PDF format
- **UAE**: United Arab Emirates
- **UDF**: User-defined function in DAX
- **UI**: User interface.
- **UPN**: User principal name: sign-in name of a user, often like an email address.
- **URI**: Uniform resource identifier
- **USA**: United States of America
- **USD**: United States dollar
- **User owns data**: Embedding model where each user signs in with Microsoft Entra ID. Also called embed for your organization.
- **UTC**: Coordinated Universal Time
- **V-Order**: Parquet write optimization that improves compression for Direct Lake
- **VAR**: DAX keyword that stores an expression result under a name
- **Verified answer**: Author-defined visual returned for trigger phrases in Copilot
- **VertiPaq**: In-memory columnar engine used by Import and Direct Lake
- **VertiPaq Analyzer**: Metrics view showing memory use by table and column
- **Visual calculation**: DAX calculation that runs on a visual's own data
- **VM**: Virtual machine
- **VNet**: Virtual network
- **VNet data gateway**: Microsoft-managed gateway injected into an Azure virtual network
- **VPAX**: VertiPaq Analyzer export file
- **VS**: Visual Studio, as used in the file that mentions it
- **VUE**: Pearson VUE, the exam delivery provider (written Pearson VUE).
- **Warehouse**: Fabric relational store built with T-SQL and multi-table transactions.
- **WCAG**: Web Content Accessibility Guidelines.
- **WebView2**: Microsoft Edge engine component that Desktop needs.
- **Workspace**: Container for reports, models and other items with roles Admin, Member, Contributor, Viewer.
- **Workspace app**: App built from one workspace with audiences and navigation; formerly called a Power BI app.
- **Workspace identity**: Fabric workspace-level identity used for authentication
- **Workspace type**: Setting that ties a workspace to a license and capacity type; formerly called license mode.
- **XLSX**: Excel workbook file format.
- **XMLA**: XML for Analysis, the endpoint protocol for semantic model tools
- **xmSQL**: Readable text form of storage engine requests
- **YTD**: Year to date
