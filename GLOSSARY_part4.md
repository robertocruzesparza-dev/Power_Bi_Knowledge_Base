# Glossary part 4

Parts: [GLOSSARY](GLOSSARY.md) | [part 2](GLOSSARY_part2.md) | [part 3](GLOSSARY_part3.md) | [part 4](GLOSSARY_part4.md) | [part 5](GLOSSARY_part5.md)

- **PPTX**: PowerPoint file format.
- **PPU**: Premium Per User license: most Premium features per user, no Fabric capacity.
- **PQT**: Label as it appears in a source table; expansion not verified
- **Prep data for AI**: Power BI tooling for AI data schema, instructions and verified answers
- **Preview feature**: Feature in test, toggled in Options; may change; limited support.
- **Privacy level**: Classification of a source as None, Private, Organizational or Public
- **Pro**: Power BI Pro per-user license for publishing and sharing.
- **Purview**: Microsoft Purview: compliance suite that hosts sensitivity labels and audit search.
- **PY**: Python
- **Q&A**: Natural-language question feature, retiring Feb 2027
- **Query folding**: Translation of M steps into a source query so the source does the work
- **QVD**: Qlik data file format used to store tables.
- **RADACAD**: Reza Rad's Power BI training and consulting site.
- **RAM**: Random-access memory
- **RangeEnd**: Reserved Power Query parameter for incremental refresh end
- **RangeStart**: Reserved Power Query parameter for incremental refresh start
- **RDL**: Report Definition Language, file format of paginated reports.
- **Regular relationship**: Relationship whose one side is guaranteed unique; supports table expansion
- **Report Builder**: Power BI Report Builder: free desktop authoring tool for paginated reports.
- **Report Server**: Power BI Report Server: on-premises report host.
- **REST**: Representational state transfer, the style of the Power BI REST API.
- **RFC**: Request for Comments, an internet standards document
- **RLS**: Row-level security.
- **Row context**: The current row during calculated column or iterator evaluation
- **SaaS**: Software as a service.
- **SAML**: Security Assertion Markup Language, a single sign-on standard
- **SAP**: SAP SE enterprise software vendor
- **SAS**: Shared access signature, a time-limited storage access token
- **SCOM**: System Center Operations Manager
- **Scorecard**: Collection of goals tracked in the Power BI service.
- **SDK**: Software development kit; the Power BI visuals SDK builds custom visuals.
- **SDMX**: Statistical Data and Metadata eXchange
- **SE**: Storage engine, the part that scans data fast and in parallel
- **SELECTEDMEASURE**: DAX function returning the measure being evaluated inside a calculation item
- **Semantic model**: Tables, relationships, measures and security that reports use; formerly dataset.
- **Service principal**: Identity of a Microsoft Entra app used for unattended access to Power BI APIs.
- **Shared view**: A filtered report link that expires 180 days after last use.
- **Shortcut**: OneLake pointer to data in another location, with no copy.
- **SIEM**: Security information and event management tool.
- **SIS**: Label in a connector list; expansion not verified
- **SKU**: Stock-keeping unit; a capacity size such as F64.
- **SM**: Semantic model, as abbreviated in some connector tables
- **Smoothing**: Spreading compute usage over future time windows
- **Source group**: Set of tables from one engine: the Vertipaq cache or one DirectQuery source
- **SPN**: Service principal name (Kerberos)
- **SPO**: SharePoint Online
- **SQL analytics endpoint**: Read-only T-SQL surface over lakehouse or mirrored Delta tables.
- **SQLBI**: Marco Russo and Alberto Ferrari's DAX and modeling site.
- **SR**: Service request
- **SSAS**: SQL Server Analysis Services.
- **SSD**: Solid-state drive
- **SSDT**: SQL Server Data Tools.
- **SSL**: Secure Sockets Layer
- **SSMS**: SQL Server Management Studio
- **SSO**: Single sign-on
- **SSRS**: SQL Server Reporting Services.
- **Star schema**: Model design with dimension tables for filtering and fact tables for summarizing
- **Storage engine**: Multi-threaded part that scans compressed column data
- **Tablix**: Report Builder region type that combines table, matrix, and list.
- **Tabular Editor**: Tool to edit Tabular Object Model; TE2 free, TE3 commercial
- **TB**: Terabyte
- **TCP**: Transmission Control Protocol
- **Tenant**: The organization's Microsoft Entra directory where Fabric and Power BI run.
- **TGGAU**: Token-Groups-Global-And-Universal Active Directory attribute
- **Theme**: JSON or built-in set of colors, fonts, and visual defaults applied to a report.
- **Throttling**: Fabric delaying or rejecting new operations when future capacity is used up.
- **TIBCO**: TIBCO Software, vendor of data products
- **TIFF**: Tagged Image File Format
- **Timepoint**: A 30-second slice of capacity time.
- **TLS**: Transport Layer Security: protocol that encrypts data in transit.
- **TMDL**: Tabular Model Definition Language: text format for semantic models.
- **TMDL view**: Desktop view for scripting model objects as TMDL code.
- **TMSL**: Tabular Model Scripting Language
- **TOM**: Tabular Object Model client library.
- **Tooltip page**: A report page sized as a tooltip and shown on hover.
