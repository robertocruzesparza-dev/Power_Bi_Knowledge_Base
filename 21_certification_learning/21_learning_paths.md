## Purpose

This file points to the official, free learning material that maps to the PL-300 and DP-600 exams. Titles and URLs were checked on 2026-10-07.

## Power BI learning sequence

The Microsoft Learn Power BI hub (updated 2026-06-26) suggests this order. Fact.

| Step | Learning path | Covers |
|---|---|---|
| 1 | Get started with Microsoft data analytics (path slug data-analytics-microsoft) | Get, clean, and transform data with Power Query in Desktop |
| 2 | Model data with Power BI (slug model-data-power-bi) | Relationships and calculations in Desktop |
| 3 | Build Power BI visuals and reports (slug build-power-bi-visuals-reports) | Modeling, visualizing, analyzing data |
| 4 | Instructor-led course PL-300T00 | Classroom or virtual course for the exam |
| 5 | Practice assessment | Readiness check for PL-300 |

Paths are under `https://learn.microsoft.com/en-us/training/paths/<slug>/`. A broader starter path, "Get started with Power BI" (slug get-started-power-bi), is also linked from the hub.

## Fabric learning path

"Get started with Microsoft Fabric" is a beginner path with 8 modules (page dated 2026-05-01). Fact.

1. Introduction to end-to-end analytics using Microsoft Fabric.
2. Get started with lakehouses in Microsoft Fabric.
3. Get started with data warehouses in Microsoft Fabric.
4. Get started with Real-Time Intelligence in Microsoft Fabric.
5. Get started with data science in Microsoft Fabric.
6. Get started with SQL Database in Microsoft Fabric.
7. Design semantic models for scale in Microsoft Fabric.
8. Understand Microsoft Fabric IQ fundamentals.

Prerequisite: basic data concepts such as engineering, modeling, and analysis. The path is a good base for DP-600 and DP-700.

## Adoption and planning guidance

The "Power BI implementation planning" series complements the Fabric adoption roadmap. It groups usage scenarios into content collaboration and delivery, self-service BI, content management and deployment, and embedding and hybrid. It is useful for the "Manage and secure" part of PL-300 and for real deployments. Fact.
