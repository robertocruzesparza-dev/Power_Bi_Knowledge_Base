## Purpose

This is a pointer list, not a summary of their content. The KB cites these sites; it does not reproduce them. Tiers follow the KB scale: 2 is expert, 3 is community.

Fact for the SQLBI, RADACAD, and Chris Webb rows (read from their home pages). Guy in a Cube details come from search summaries, so treat job titles and counts as unverified.

## How to use these sources

- Start with Microsoft docs for features and limits. Use experts for patterns, performance, and design opinion.
- When an expert post disagrees with Microsoft docs, check the post date. Product behavior changes monthly.
- Label expert advice as opinion unless it cites a test you can repeat.
