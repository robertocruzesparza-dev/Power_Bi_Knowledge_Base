## Purpose

PL-300 is the exam for the Microsoft Certified: Power BI Data Analyst Associate credential. It tests the full analyst workflow in Power BI, from loading data to securing content.

## Key facts

- Exam code: PL-300. Credential: Power BI Data Analyst Associate. Level: intermediate. Role: data analyst. Fact.
- Page last updated 2026-04-20; the current skills list is dated 2026-04-20. Fact.
- Duration: 100 minutes. The exam is proctored and can include interactive components. Fact.
- Passing score: 700 or higher on the standard scaled score. Fact.
- Languages: English, Japanese, Chinese (Simplified), Korean, German, French, Spanish, Portuguese (Brazil), Chinese (Traditional), Italian. Fact.
- Retake: allowed 24 hours after a first failed attempt. Later waits vary; see the Microsoft retake policy. Fact.
- Renewal: the credential lasts 12 months. A free, unproctored, open-book online assessment on Microsoft Learn renews it. Fact.
- Price: depends on the country where you sit the exam. Microsoft's exam FAQ says associate and expert exams typically cost US$165, priced by country, and taxes may apply. Exam pages show only a country-based price at scheduling. Fact; the exact local amount is unverified.
- Study guide re-checked 2026-10-08: weights and the 2026-04-20 skills list unchanged. The 100-minute duration is not stated on the study guide or certification page; treat it as unverified here. Fact.

## Skill areas and weights

| Area | Weight | Main topics |
|---|---|---|
| Prepare the data | 25-30% | Connect to sources or shared semantic models, parameters, profile and clean data, transform and load |
| Model the data | 25-30% | Relationships, cardinality, date tables, DAX measures, calculation groups, performance |
| Visualize and analyze the data | 25-30% | Visual choice, formatting, themes, bookmarks, drillthrough, accessibility, AI visuals, forecasting |
| Manage and secure Power BI | 15-20% | Workspaces, apps, subscriptions, alerts, refresh, workspace roles, row-level security (RLS), sensitivity labels |

## What the April 2026 update emphasizes

The 2026-04-20 skills list names these items explicitly (Fact, from the study guide):

- Choosing between Direct Lake, DirectQuery, and Import.
- Visual calculations written in DAX, and quick measures.
- Copilot tasks: narrative visuals, creating or suggesting report pages, summarizing a semantic model.
- Personalized visuals, sync slicers, export settings, and automatic page refresh.
- Choosing a distribution method and configuring an app, subscriptions, and data alerts.
- Promoting or certifying content, and knowing when a gateway is required.

The change log marks the "Get or connect to data", "Enhance reports", and "Create and manage workspaces and assets" areas as minor changes.

## Preparation steps

1. Read the study guide and tick each bullet you can do in Desktop and the service.
2. Work through the Microsoft Learn Power BI learning paths ([Learning paths](21_learning_paths.md)).
3. Take the free practice assessment on Microsoft Learn to find weak areas.
4. Try the exam sandbox to learn the question interface.
5. Rehearse the service tasks hands-on: workspace roles, app audiences, scheduled refresh, subscriptions.

## Common mistakes

- Studying only Desktop. About 15-20% of the exam covers service administration tasks.
- Memorizing menu paths. Interface text changes; the study guide lists skills, not clicks.
- Ignoring Copilot and AI items. They now appear in the visualize area.

## Limits and version notes

- Exams change periodically. Microsoft updates the English exam first and localized versions about eight weeks later. Fact.
- Questions mostly cover generally available features. Preview features can appear if commonly used. Fact.
- Re-check the study guide date before booking. Skill lists can change without notice.
