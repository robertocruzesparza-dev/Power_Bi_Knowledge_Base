# Glossary part 2

Parts: [GLOSSARY](GLOSSARY.md) | [part 2](GLOSSARY_part2.md) | [part 3](GLOSSARY_part3.md) | [part 4](GLOSSARY_part4.md) | [part 5](GLOSSARY_part5.md)

- **DIN**: A font family used by Power BI theme defaults for callouts and titles.
- **Direct Lake**: Storage mode that queries OneLake data without import.
- **DirectLakeBehavior**: Model property for Direct Lake on SQL: Automatic, DirectLakeOnly, or DirectQueryOnly.
- **DirectQuery**: Storage mode that sends a query to the source for each visual instead of importing data
- **DLL**: Dynamic link library
- **DLP**: Data loss prevention: policies that detect and block sharing of sensitive data.
- **DMV**: Dynamic Management View: a query that reads model metadata and storage statistics.
- **DOCX**: Word document file format, an attachment type for paginated report subscriptions.
- **DP**: Prefix of Microsoft data platform exam codes such as DP-600 and DP-700.
- **DP-600**: Exam code for Microsoft Certified: Fabric Analytics Engineer Associate.
- **DP-700**: Exam code for Microsoft Certified: Fabric Data Engineer Associate.
- **DP-900**: Exam code for Microsoft Certified: Azure Data Fundamentals.
- **DQ**: DirectQuery storage mode
- **Drillthrough**: Navigation from one report page to another filtered to a selected item.
- **Dual**: Table storage mode that acts as Import or DirectQuery per query
- **DW**: Data warehouse
- **EA**: Enterprise Agreement: a Microsoft volume licensing contract.
- **EM**: Name of a Power BI Premium capacity SKU series (EM SKUs); see licensing domain for status
- **EM SKU**: Power BI Embedded SKU for embedding in Microsoft 365 apps; supports only Power BI items.
- **EM/A SKU**: Power BI Embedded SKUs, not part of the P SKU retirement.
- **Embed token**: Short-lived credential created by a back end so a browser can open specific Power BI items in the app-owns-data model.
- **EMF**: Enhanced Metafile image format
- **Endorsement**: Promoted, Certified, or Master data badge applied to an item.
- **Enhanced compute engine**: Gen1 dataflow SQL cache engine for Premium A3/P1 and above.
- **Enhanced refresh**: REST API refresh mode with table, partition, batch, and cancel control.
- **Entra**: Microsoft Entra ID, the identity directory that defines a tenant.
- **ESRI**: Esri, the maker of ArcGIS map visuals that are unsupported in subscriptions.
- **ETL**: Extract, transform, load.
- **EU**: European Union
- **EUR**: Euro currency code
- **F SKU**: Fabric capacity bought in Azure, sizes F2 to F8192.
- **F32**: Fabric capacity SKU size 32; free users cannot view content on it without a paid license.
- **F64**: Fabric capacity SKU size 64; the smallest size on which free users can view Power BI content.
- **Fabric (Free)**: Free per-user license auto-assigned at first Fabric sign-in.
- **Fabric administrator**: Admin role that manages Fabric and Power BI tenant settings.
- **Fabric CLI**: Open-source command line (fab) for Fabric items.
- **Fabric Copilot capacity (FCC)**: Capacity designated to collect Copilot billing for a user group
- **fabric-cicd**: Microsoft-backed open-source Python library that deploys Fabric items from source control.
- **Fact table**: Table of events or measurements with keys and numeric columns
- **Fallback**: Direct Lake on SQL switching a query to DirectQuery against the SQL analytics endpoint.
- **FAQ**: Frequently asked questions
- **Fast Combine**: Option to ignore privacy levels when combining data
- **Fast copy**: Dataflow Gen2 parallel ingestion mode for large data.
- **FE**: Formula engine, the DAX query engine part that runs single-threaded logic
- **Filter context**: The set of filters applied to columns when a measure is evaluated
- **Formula engine**: Single-threaded part of query processing that runs DAX logic
- **Formula.Firewall**: Error raised when the Data Privacy Firewall blocks a query
- **FQDN**: Fully qualified domain name
- **Framing**: Direct Lake refresh that sets a point-in-time view of Delta tables
- **FS**: Federation Services, as in AD FS (Active Directory Federation Services)
- **GA**: Generally available
- **Gateway cluster**: Group of up to 10 on-premises gateway installations for high availability
- **GB**: Gigabyte.
- **GCC**: Government Community Cloud: US government Microsoft cloud environment.
- **GCS**: Google Cloud Storage.
- **GIF**: Graphics Interchange Format image
- **GMT**: Greenwich Mean Time
- **Grain**: The level of detail one fact table row represents
- **GUID**: Globally unique identifier
- **HANA**: SAP HANA in-memory database
- **HAR**: HTTP archive file of browser network traffic
- **HCAAT**: How Copilot arrived at this: Copilot answer detail view
- **HITRUST**: Organization and framework for security and privacy assurance certification
- **HSM**: Hardware security module
- **HTTP**: Hypertext Transfer Protocol.
- **HTTPS**: Secure Hypertext Transfer Protocol
- **Hybrid table**: Table with Import partitions plus one DirectQuery partition
- **IAM**: Identity and access management
- **IBM**: International Business Machines
- **IDE**: Integrated development environment
- **IEEE**: Institute of Electrical and Electronics Engineers, publisher of floating-point standards
- **IError**: Error object returned by the Power BI JavaScript embedding SDK
- **Incremental refresh**: Refreshing only recent partitions of a table
- **IP**: Internet Protocol, as in IP address
- **IQ**: Intelligence; as in Microsoft Fabric IQ, a Fabric workload area for shared business concepts.
