# Glossary part 1

Parts: [GLOSSARY](GLOSSARY.md) | [part 2](GLOSSARY_part2.md) | [part 3](GLOSSARY_part3.md) | [part 4](GLOSSARY_part4.md) | [part 5](GLOSSARY_part5.md)

- **A SKU**: Power BI Embedded SKU bought in Azure; supports only Power BI items.
- **AAD**: Azure Active Directory, now Microsoft Entra ID
- **AAS**: Azure Analysis Services.
- **ACID**: Atomicity, consistency, isolation, durability: transaction guarantees.
- **AD**: Active Directory
- **ADBC**: Arrow Database Connectivity, a driver standard used by newer Snowflake and Impala connectors
- **ADFS**: Active Directory Federation Services, an identity sign-in method not supported for on-premises SharePoint refresh.
- **ADLS**: Azure Data Lake Storage.
- **ADLS Gen2**: Azure Data Lake Storage Gen2, the storage service under OneLake.
- **ADP**: Vendor label in a connector list; expansion not verified
- **Advanced Editor**: Power Query window that shows and edits the full M script of a query
- **Aggregation table**: Hidden summarized table that answers coarse queries for a detail table
- **ALM**: Application lifecycle management.
- **ALM Toolkit**: Open-source schema compare tool for Power BI semantic models.
- **AM**: Ante meridiem, time before noon
- **Anomaly detection**: Line chart feature that flags points outside an expected range
- **App owns data**: Embedding model where the app authenticates for all users; viewers need no Power BI license. Also called embed for your customers.
- **Applied steps**: The ordered list of transformation steps shown in the Power Query query settings pane
- **Approved for Copilot**: Semantic model flag that removes friction treatment in standalone Copilot
- **ARM**: Azure Resource Manager
- **Audience**: A group of users who see a chosen set of items in an app.
- **Autobinding**: Pipeline behavior that points a deployed report at the paired model in the target stage.
- **AWS**: Amazon Web Services
- **B2B**: Business-to-business guest access through Microsoft Entra, used to invite external users.
- **BCDR**: Business continuity and disaster recovery.
- **BI**: Business intelligence.
- **BIM**: File format of a Tabular model definition (model.bim)
- **BMP**: Bitmap image format
- **BOM**: Byte order mark, a marker at the start of a text file
- **Bookmark**: Saved state of a report page including filters, visibility, and drill location.
- **BPA**: Best Practice Analyzer: rule checker in Tabular Editor
- **BQE**: Vendor label in a connector list; expansion not verified
- **Bravo**: SQLBI desktop tool for model analysis, DAX formatting, date tables and export
- **Build permission**: Semantic model permission that lets a user create new content on the model and use it outside Power BI (called explore in the REST API).
- **Bursting**: Fabric running work above the SKU compute for a short time.
- **BYOK**: Bring your own key: customer-supplied key that encrypts imported Power BI semantic models.
- **Calculation group**: Table of calculation items that apply a DAX pattern to many measures
- **Capacity**: Dedicated compute pool a workspace can run on.
- **Capacity Metrics app**: Fabric app showing capacity usage and throttling
- **Cardinality**: Relationship type (one-to-many, many-to-many) or count of distinct values in a column
- **Carryforward**: Overage compute debt that burns down over time
- **CC**: Vendor or product label in a connector list; expansion not verified
- **CCH**: Vendor label in a connector list; expansion not verified
- **CD**: Continuous deployment
- **CDM**: Common Data Model, a shared data schema standard
- **CI**: Continuous integration
- **CI/CD**: Continuous integration and continuous delivery.
- **CLI**: Command-line interface
- **CMK**: Customer-managed key: customer key in Azure Key Vault used to encrypt Fabric workspace data.
- **CNN**: Convolutional neural network
- **COE**: Center of Excellence: internal team that guides and supports analytics users.
- **Composite model**: Semantic model mixing storage modes or sources
- **Context transition**: Conversion of row context into filter context by CALCULATE
- **CPU**: Central processing unit
- **Cross-filter direction**: Which way a relationship passes filters: single or both
- **CRUD**: Create, read, update, delete operations in an API
- **CSF**: HITRUST Common Security Framework
- **CSP**: Cloud Solution Provider: Microsoft partner that sells and manages cloud subscriptions.
- **CU**: Capacity unit; measure of compute power of a Fabric SKU.
- **DA**: Label as it appears in a source; expansion not verified
- **Data Privacy Firewall**: Power Query component that stops data moving between sources of incompatible privacy levels
- **Dataflow Gen1**: Legacy Power BI dataflows in Power BI workspaces.
- **Dataflow Gen2**: Fabric Power Query Online data preparation item
- **Datamart**: Retired Power BI self-service managed database; replaced by Fabric warehouse.
- **Dataset**: Former name of semantic model.
- **DAX**: Data Analysis Expressions, the formula and query language of the model.
- **DAX query view**: Desktop and web view for running DAX queries with EVALUATE.
- **DAX Studio**: Free tool for running and tracing DAX queries
- **DB**: Database
- **DD**: Label as it appears in a source table; expansion not verified
- **DE**: German locale country code, as in de-DE
- **Decomposition tree**: AI visual that breaks a measure down across dimensions
- **Delta**: Open table format of Parquet files plus a transaction log, used by Fabric.
- **Deployment rule**: Pipeline setting that swaps a data source, parameter, or default lakehouse in a target stage.
- **Dimension table**: Table of descriptive entities used to filter and group
