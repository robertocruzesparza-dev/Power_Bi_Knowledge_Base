# Glossary part 3

Parts: [GLOSSARY](GLOSSARY.md) | [part 2](GLOSSARY_part2.md) | [part 3](GLOSSARY_part3.md) | [part 4](GLOSSARY_part4.md) | [part 5](GLOSSARY_part5.md)

- **ISO**: International Organization for Standardization; here the ISO date format used in theme files.
- **IT**: Information technology
- **Iterator**: DAX function ending in X that evaluates an expression for each row
- **JPEG**: Joint Photographic Experts Group image format
- **JS**: JavaScript
- **KB**: Knowledge base.
- **Kerberos constrained delegation**: Active Directory single sign-on method used by the gateway
- **Key influencers**: AI visual that ranks factors driving a metric
- **KeyTips**: Letter hints shown over ribbon commands when Alt is pressed.
- **KPI**: Key performance indicator, a visual that shows progress to a target.
- **KQL**: Kusto Query Language used in Fabric Real-Time Intelligence and DP-600 and DP-700.
- **KX**: Vendor label in a connector list (KX Systems); expansion not needed
- **Lakehouse**: Fabric item combining files and Delta tables, worked on with Spark and read by SQL.
- **Large semantic model storage format**: Setting that lets Import models exceed 1 GB on paid capacity.
- **Limited relationship**: Many-to-many or cross source group relationship with no guaranteed one side
- **Live connection**: Report connected to a published semantic model without copying data.
- **LLAP**: Live Long and Process, Hive query daemon
- **LLM**: Large language model
- **LOD**: Level of detail: Tableau expressions that set aggregation grain; mapped to DAX CALCULATE patterns.
- **LSDL**: Linguistic schema definition language file storing AI instructions and schemas
- **M**: Power Query formula language
- **M365**: Microsoft 365.
- **Master user**: A normal licensed account used by an app to call Power BI non-interactively.
- **MB**: Megabyte.
- **MCP**: Model Context Protocol, a standard for connecting AI tools to data and services
- **MDX**: Multidimensional Expressions query language
- **MFA**: Multifactor authentication.
- **MHTML**: Web archive file format.
- **MIME**: Multipurpose Internet Mail Extensions
- **Mirroring**: Fabric feature that replicates an external database or catalog into OneLake.
- **MIT**: MIT open-source software license
- **ML**: Machine learning.
- **ML.NET**: Microsoft machine learning library used by AI visuals
- **MM**: Month in a date format string
- **MSAL**: Microsoft Authentication Library.
- **MSI**: Windows Installer package format.
- **Multi-Geo**: Fabric feature to place capacities and their data in regions other than the tenant home region.
- **My workspace**: Personal workspace of each user.
- **Native query**: A query written in the source's own language, such as SQL, run via Value.NativeQuery
- **NET**: Microsoft .NET framework
- **NL2DAX**: Natural language to DAX
- **NL2KQL**: Natural language to KQL
- **NL2SQL**: Natural language to SQL
- **NT**: Windows NT, as in NT account
- **NTLM**: NT LAN Manager, a Windows authentication protocol supported for on-premises SharePoint refresh.
- **OAuth**: Open authorization token protocol
- **OD**: On-demand, a label on some billing meters; meaning of newer meters is unverified
- **ODBC**: Open Database Connectivity, a driver standard for database access
- **OLS**: Object-level security
- **OneLake**: Fabric's single logical data lake built on ADLS Gen2.
- **Open mirroring**: Mirroring where your own app writes change data to a landing zone.
- **Org app**: Fabric item type that packages items from a workspace; several allowed per workspace.
- **ORK**: Label in a connector list; expansion not verified
- **P SKU**: Power BI Premium per-capacity SKU P1 to P5; being retired at agreement end.
- **Paginated report**: Pixel-perfect, printable report built in Report Builder.
- **Pairing**: Link between an item in one pipeline stage and the same item in the adjacent stage.
- **Parquet**: Columnar file format underlying Delta tables.
- **PAYG**: Pay-as-you-go: billing by usage without commitment.
- **PBIP**: Power BI Project: folder of text files plus a pointer .pbip file.
- **PBIR**: Power BI enhanced report format: report stored as many small JSON files.
- **PBIR-Legacy**: Older single-file report.json report format.
- **PBIRS**: Power BI Report Server: on-premises report server.
- **PBIT**: Power BI template file: report and model definitions without data.
- **pbiviz**: Command line tool and package format for building Power BI custom visuals.
- **PBIX**: Power BI Desktop report file containing report, model and data.
- **PDF/UA**: Accessible PDF standard.
- **Performance Analyzer**: Desktop pane that times each visual
- **Personal mode gateway**: Single-user gateway that supports Import refresh for Power BI only
- **PL**: Prefix of Microsoft Power Platform exam codes such as PL-300.
- **PL-300**: Exam code for Microsoft Certified: Power BI Data Analyst Associate.
- **PNG**: Portable Network Graphics image
- **Power BI**: Microsoft business analytics platform; a core workload of Microsoft Fabric.
- **Power BI Desktop**: Free Windows app for connecting, modeling and building reports.
- **Power BI service**: Cloud site (app.powerbi.com) for publishing, sharing, refresh and collaboration.
- **PPM**: Product label in a connector list (Hexagon PPM); not expanded
